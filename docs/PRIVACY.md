# 隐私与数据

默认数据目录为 `%LOCALAPPDATA%\SideDock`：配置、备份、历史、Browser 用户数据、便笺和图标缓存。Cookie 和网站存储由 WebView2 管理；不是主浏览器的用户配置。

应用不向自建服务器上传配置、便笺或历史。你访问的网站仍然会联网，并可能收集信息、请求权限或处理账号数据。不会自动导入主浏览器登录状态。

历史最多 10,000 条，每个入口保留最多 200 个后退地址。退出后复制整个目录可以备份；卸载保留个人数据。不要将该目录、登录 Cookie、聊天记录或真实配置上传到 Issues。

运行中保留网页实例不等于重启后保存全部页面内存；未保存的输入和流式回答可能丢失。不要把便笺当成唯一备份。

多篇笔记保存在 `https://sidedock.internal` 的 WebView2 localStorage，键名 `sidedock.notebook.v1`；原单页键 `notes` 保留作为迁移备份。数据与删除回收区共享浏览器存储配额。导出的 JSON 包含全部正文和回收区，请自行保管。导入会追加在用笔记，不覆盖原内容，也不会自动恢复备份中的回收区。旧版本只认识旧单页键，降级不能读取新增笔记。
