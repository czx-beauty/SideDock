# 已知限制

- 预发布版，未签名；第三方网站与 OAuth / 企业认证兼容性需逐站确认。
- 没有代用户登录真实 DeepSeek、Google 或 YouTube；可控测试页通过不等于真实业务全部兼容。
- 鼠标热边缘、多 DPI 多屏、睡眠恢复与触控板原始位移需要更多实机验收。
- 已使用的网站保持活动可能增加内存，隐藏视频可能继续播放。
- 重启恢复 URL 与网站存储，滚动和视频位置为尽力恢复，不保证草稿和临时回答。
- 不支持扩展、多账号隔离、云同步、MCP 或自动更新。
- 发行包包含构建时选择的 .NET 8.0.17 运行时；尚未实现运行时更新机制，维护发行版时需主动审查运行时更新与安全公告。
